## Quick Start

1. Open `MODEL_SPECIFICATION.txt`
2. Replace every occurrence of the placeholder `[MODEL_NAME]` with your desired model name
3. Use the entire contents of the file as the system prompt for your inference runtime

That is all that is required.

---

## Design Intent

The specification unites:

- The sparse attention efficiency, coding strength, and agentic performance of **DeepSeek-V4.1-Flash-1017** (including its NVIDIA NVFP4 quantized form)
- The long-horizon reasoning, secure code generation, vulnerability discovery, and patching capabilities of the latest **Google Gemini 4 Carbon / Xenon-class** frontier models

It is deliberately written in a formal, hierarchical, highly detailed register reminiscent of classic Apple system documentation of the 1980s and 1990s.

---

## Usage Notes

- The document is both a **technical specification** and a **complete system prompt**.
- No additional prompt engineering is required once the name placeholder is substituted.
- The formal tone of the documentation may be mildly reflected in the model’s responses when high technical precision is appropriate.
